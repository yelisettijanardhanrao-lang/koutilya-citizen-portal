Name Difference Affidavit

Online preparation of a single affidavit

Use: This service is for a declaration explaining a difference between a person's correct/preferred name and the name appearing in a particular record. The receiving authority may prescribe its own correction form, declaration, Gazette process or other evidence.

Before signing: Check the original documents carefully and use the exact names as they appear on those documents.

Keep ready

  • Identity document with correct name
  • Document showing the different name
  • Supporting proof of identity/address
  • Any authority-specific correction form
Important
There is no single India-wide stamp-paper value or acceptance rule for every name discrepancy. Verify the receiving authority's current requirement before execution/notarisation.
