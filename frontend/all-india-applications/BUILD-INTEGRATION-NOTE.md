This module is prepared for integration into the production Citizen Portal. The existing main portal loads frontend/index.html and frontend/portal-app.js. Include meeseva-portal-module.css and meeseva-portal-module.js after the portal UI scripts. The module intercepts the existing MeeSeva Applications navigation and renders four state cards, application cards, and same-tab one-page input forms. Submit must call the authenticated application save endpoint, then the server-side ₹2 payment endpoint; only after successful payment should Generate PDF appear. Do not expose a client-only wallet deduction.
