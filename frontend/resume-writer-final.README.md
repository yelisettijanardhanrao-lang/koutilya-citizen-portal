# Koutilya Resume Writer — Locked Build Specification

This branch implements only the locked Resume Writer flow confirmed by the user.

1. Display five actual A4 design previews first.
2. User selects one design.
3. AI interview starts only after selection.
4. Interview is conversational, one question at a time; it is not a conventional long form.
5. AI validates answers and asks follow-ups where needed; never invents facts.
6. AI prepares professional resume content.
7. Candidate reviews facts and can correct them.
8. Selected A4 design is applied.
9. Professional A4 live preview is shown.
10. Candidate can edit / AI improve.
11. Final review.
12. Generate PDF.
13. Deduct exactly ₹10 only after successful PDF generation.
14. Download clean candidate PDF without Koutilya branding/watermark.

Five locked designs:
- Modern Professional
- Elegant Sidebar
- Clean Corporate
- Premium Timeline
- Premium Two-Column

Do not replace this flow with a multi-step conventional form, change the order, remove template selection, or introduce a different template set without explicit user approval.
